# 질문이 배움이 되는 순간 — 학생용 수업·탐구·세특 안내서

고등학생이 수업의 궁금증을 탐구로 이어 가고, 세특(세부능력 및 특기사항)을 준비하는 과정을 돕는 단일 HTML 페이지입니다. 외부 글꼴·이미지·서버 없이 파일 하나로 동작합니다.

## 1. 깃허브 Pages로 배포하기 (가장 추천하는 방법)

학생들이 코드를 볼 필요 없이 **웹 링크(URL)** 하나로 바로 접속하게 하려면 이 방법을 쓰세요.

1. 이 저장소를 GitHub에 올립니다. (`index.html`이 저장소 최상위 폴더에 있어야 합니다.)
2. 저장소 페이지에서 **Settings → Pages**로 이동합니다.
3. **Branch**를 `main`(또는 배포할 브랜치), 폴더를 `/ (root)`로 선택하고 저장합니다.
4. 1~2분 후 다음과 같은 형태의 주소가 발급됩니다.
   ```
   https://<깃허브아이디>.github.io/<저장소이름>/
   ```
5. 이 주소를 학생들에게 카카오톡·문자·학급 게시판 등으로 공유하면, 학생은 클릭만으로 브라우저에서 바로 볼 수 있습니다.

> 파일명이 반드시 `index.html`이어야 저장소 주소만으로 바로 열립니다. 다른 이름(특히 한글 파일명)을 쓰면 주소가 길고 복잡해져 공유하기 어렵습니다.

## 2. 링크 없이 파일만 나눠 줄 경우

GitHub Pages를 쓰지 않고 `index.html` 파일 자체를 전달한다면, 학생에게 이렇게 안내해 주세요.

1. 받은 파일을 내 컴퓨터(또는 스마트폰) 다운로드 폴더에 저장합니다.
2. 파일을 마우스 오른쪽 버튼(스마트폰은 길게 누르기)으로 클릭합니다.
3. **연결 프로그램 → Chrome(또는 Safari, Edge)** 를 선택해서 엽니다.
   - 스마트폰에서 파일 앱을 통해 열 경우, 상단 공유 아이콘에서 "브라우저로 열기"를 선택합니다.
4. 화면이 깨지거나 글씨가 이상하게 보이면 다른 브라우저로 다시 열어 보세요. (인터넷 익스플로러는 지원하지 않습니다.)

## 3. 배포 전 체크리스트 (선생님용)

- [ ] `og-image.png` 관련 태그: `index.html` 상단의 `<meta property="og:image" ...>` 주소를 실제 저장소 이미지 경로로 바꾸거나, 이미지가 없다면 그 줄을 삭제하세요. (그대로 두면 카톡 공유 시 미리보기 이미지만 안 뜨고, 페이지 자체는 정상 작동합니다.)
- [ ] 학교 실제 규정 링크: 09번 섹션(협업과 학교생활) 끝에 **"[학교 홈페이지의 생활규정·학생인권규정 링크를 여기에 추가하세요]"** 라는 문구가 있습니다. Ctrl+F(또는 Cmd+F)로 이 문구를 찾아 실제 학교 규정 페이지 링크로 바꿔 주세요. 이 안내서에는 교복·기기 사용·상벌점 등 학교마다 다른 실제 규정이 포함되어 있지 않습니다.
- [ ] 워크시트(15번 섹션) 메모는 학생의 **브라우저에만** 저장됩니다(localStorage). 서버로 전송되지 않으며, 다른 기기·다른 브라우저에서는 보이지 않습니다. 완성한 내용은 학생이 한글·워드 등 개인 문서로 옮겨 보관하도록 이미 페이지 안에서 안내하고 있습니다.
- [ ] 학교 공용 컴퓨터(컴퓨터실 등)에서 사용할 경우, 다음 학생에게 이전 메모가 보이지 않도록 워크시트의 **"메모 지우기"** 버튼을 쓰도록 안내해 주세요.

## 4. 자주 있는 질문

**Q. 학생들이 검색이나 필터를 못 쓴다고 해요.**
A. 학교 네트워크에서 자바스크립트를 차단하는 경우, 검색·필터 기능만 작동하지 않고 61개 예시 전체는 그대로 페이지에 보입니다(정적으로 미리 렌더링되어 있음). 필터가 필요하면 Ctrl+F로 과목명을 검색하도록 안내해도 됩니다.

**Q. 내용을 수정하고 싶어요.**
A. `index.html`은 일반 텍스트 파일이라 메모장이나 VS Code로 열어 바로 수정할 수 있습니다. 61개 예시 데이터는 파일 안의 `<script id="exampleData" type="application/json">` 블록과, 그 아래 정적으로 풀어 쓴 `<div id="exampleList">` 두 곳에 함께 들어 있으니, 예시를 추가·수정할 때는 두 곳을 함께 고쳐야 합니다.

**Q. 인쇄해서 나눠 줄 수도 있나요?**
A. 네. 페이지 우측 상단 "인쇄 / PDF 저장" 버튼을 누르면 목차·워크시트 텍스트 입력칸 등 화면 전용 요소는 빠지고 본문 위주로 인쇄됩니다.
